# 🏆 WC 2026 Pick'em

World Cup 2026 **групп шатны** pick'em тоглоом. Групп бүрийн багуудыг **1–4 байраар** таамаглаж,
жинхэнэ дүнтэй тулгаж оноо цуглуулна. Найзуудтайгаа **лиг** үүсгэн өрсөлдөж, **бүх тоглогчтой**
нийт самбар дээр өрсөлдөнө.

- **Backend:** Node.js + Express + **MongoDB**
- **Frontend:** энгийн web хуудас (HTML/CSS/JS), build шаардахгүй
- **Нэвтрэлт:** зүгээр нэр/nickname (нууц үггүй). Бичих үйлдэл бүр нууц token-оор хамгаалагдсан.

---

## 1. Урьдчилсан шаардлага

- [Node.js](https://nodejs.org) 18+ (танай орчинд 25 байгаа — болно)
- MongoDB холболт:
  - **MongoDB Atlas** (үнэгүй, cloud) — [cloud.mongodb.com](https://cloud.mongodb.com), эсвэл
  - Local MongoDB (`mongodb://127.0.0.1:27017`)

> Хэрэв `MONGODB_URI`-г **хоосон** орхивол хөгжүүлэлтэд зориулж санах ойн (in-memory) MongoDB
> автоматаар асна — туршихад л зориулагдсан, өгөгдөл хадгалагдахгүй.

---

## 2. Суулгах

```bash
cd wc2026-pickem
npm install
```

`.env` файл үүсгэ (загвар нь `.env.example`):

```bash
cp .env.example .env
```

`.env` дотроо бөглө:

```ini
# Чиний MongoDB — Atlas жишээ:
MONGODB_URI=mongodb+srv://USER:PASSWORD@cluster0.xxxxx.mongodb.net/wc2026pickem?retryWrites=true&w=majority
PORT=3000
ADMIN_KEY=<урт нууц утга>     # групп бүрийн жинхэнэ дүн оруулахад
PICKS_LOCK_AT=               # (заавал биш) таамаг хаах хугацаа, ж: 2026-06-11T16:00:00Z
```

## 3. Ажиллуулах

```bash
npm start
```

Дараа нь хөтчөөр нээ: **http://localhost:3000**

---

## 4. Хэрхэн тоглох вэ?

1. **Нэрээ оруул** (nickname). Нууц үг хэрэггүй — энэ төхөөрөмжид token хадгалагдана.
2. **Таамаг** таб: групп бүрийн 4 багийг **дарж** 1→2→3→4 байраар эрэмбэл.
   Дахин дарвал сонголт цуцлагдана. **Хадгалах** товч дар.
3. **Лиг** таб: шинэ лиг үүсгэ (код гарна) эсвэл найзынхаа кодоор нэгд.
   Кодоо найзууддаа илгээ — тэд орж ирж өрсөлдөнө.
4. **Самбар** таб: дээд талын сонголтоор **Бүгд** (нийт) эсвэл аль нэг **лигийн**
   самбарыг хар.

## 5. Оноо тооцох

- Багийг **яг зөв байранд** таавал тус бүр **1 оноо** (групп бүрт дээд тал нь 4).
- 12 групп ⇒ нийт дээд тал нь **48 оноо**.
- Группын 4 байрыг бүгдийг зөв таавал «төгс групп» (tiebreak-д тооцно).
- Онооны жинг өөрчлөх бол [`server/lib/scoring.js`](server/lib/scoring.js) доторх
  `POINTS_PER_EXACT` / `PERFECT_GROUP_BONUS`-ийг засна.

## 6. Admin — жинхэнэ дүн оруулах

Групп дуусах бүрт эцсийн байрыг оруулж өгснөөр оноо автоматаар тооцогдоно.

1. Толгой дахь **🏆** тэмдгийг дар.
2. `.env` дэх **ADMIN_KEY**-ээ оруул.
3. Групп бүрийн 4 багийг жинхэнэ эцсийн байраар эрэмбэлж **Хадгалах** дар.

> Дүн орсон группийн таамгийг тоглогчид өөрчилж чадахгүй (хууран мэхлэхээс хамгаалсан).

---

## 7. Интернэтэд байршуулах (найзуудтайгаа тоглох)

Энгийн Node апп тул дараах үнэгүй platform дээр тавьж болно:

- **MongoDB:** [MongoDB Atlas](https://cloud.mongodb.com) free tier → `MONGODB_URI` авна.
- **Сервер:** [Render](https://render.com), [Railway](https://railway.app), [Fly.io](https://fly.io) гэх мэт.
  - Build command: `npm install`
  - Start command: `npm start`
  - Орчны хувьсагч (Environment): `MONGODB_URI`, `ADMIN_KEY`, (заавал биш) `PICKS_LOCK_AT`.

Deploy хийсний дараа гарсан хаягаа найзууддаа илгээ — бүгд нэг самбар дээр өрсөлдөнө.
